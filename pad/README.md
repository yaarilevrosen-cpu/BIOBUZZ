# גשר BIOBUZZ — שלט טלפון ומשחק משותף ברשת

פייתון 3.8 ומעלה. ספריית התקן בלבד — אין מה להתקין.

## מה יש בתיקייה
| קובץ | מה זה |
|---|---|
| `padbridge.py` | הגשר ושרת החדר |
| `pad.html` | דף השלט לטלפון (גם מוטמע בתוך הגשר; קובץ חיצוני מקבל עדיפות) |
| `start.bat` | הפעלה בלחיצה כפולה בוינדוס |
| `BIOBUZZ-lab.html` | הסימולטור המלא, עם המודל הרשמי של הזירה (~21 מ״ב) — שים אותו **באותה תיקייה** כדי שהגשר יגיש אותו |
| `BIOBUZZ-lab-lite.html` | אותו סימולטור בלי המודל הרשמי (~1.7 מ״ב) — לטלפון, לשליחה מהירה ולמחשבים חלשים. הפיזיקה והזירה זהות |

## הפעלה
לחיצה כפולה על `start.bat`, או:
```
python padbridge.py
```
הגשר מדפיס: כתובת הסימולטור במחשב הזה, **קוד החדר**, וכתובת הצטרפות למחשב אחר.

## משחק משותף — מחשב אחר באותה רשת
1. במחשב המארח: להריץ את הגשר, לפתוח `http://localhost:9662/sim`.
2. בסימולטור: **משחק ← משחק משותף — רשת מקומית ← פתח חדר**.
3. במחשב השני — אחת משתיים:
   - לפתוח בדפדפן את כתובת ההצטרפות שהגשר הדפיס (`http://192.168.x.x:9662/join?k=…`). הסימולטור נטען מהמארח ומצטרף לבד.
   - או לפתוח את `BIOBUZZ-lab.html` מקובץ, **משחק ← משחק משותף ← הצטרף**, ולהקליד את קוד החדר.
4. האורח מקבל את העמדה הפנויה הראשונה. בטבלה כתוב ליד כל עמדה **לצידי** או **מולי** — אפשר לעבור עם ״לשבת כאן״.

**רשת מקומית בלבד:** הגשר מסרב לכל מחשב שלא מכתובת ביתית (10.x, 172.16–31.x, 192.168.x), והסימולטור מסרב להתחבר לכתובת שאינה ביתית. הקוד הוא גם המפתח — בלעדיו אי אפשר להיכנס, גם מאותה רשת. המפתח נשמר בקובץ `.room-key` ליד הגשר, כך שהקוד לא משתנה בין הפעלות. למחוק את הקובץ = קוד חדש.

**חומת האש של וינדוס** תשאל בהפעלה הראשונה אם לאפשר לפייתון ברשת — לאשר ״רשתות פרטיות״.

## שני שחקנים על אותו מחשב — מסך מפוצל
לא צריך את הגשר בכלל. **משחק ← מסך מפוצל ← מפוצל לשניים**.
- שחקן 1: מקלדת `WASD` / `QE` / רווח, או השלט הראשון.
- שחקן 2: השלט השני, או חצים · `,` `.` סיבוב · אנטר ירי · `/` איסוף · שיפט ימני כיוון.
- בוחרים אם שחקן 2 הוא השותף האדום (ביחד) או כחול 1 / כחול 2 (אחד נגד השני).

## שלט טלפון בכבל
לחבר את הטלפון עם ״ניפוי באגים דרך USB״ פתוח. הגשר מריץ `adb reverse` לבד, ובטלפון פותחים `http://localhost:9662`. בלי adb (ברשת האלחוטית) — סורקים את קוד ה-QR בסימולטור, או פותחים את הכתובת שהגשר הדפיס (`http://192.168.x.x:9662/?p=…`). מ-1.12.5 טלפון מהרשת צריך את המפתח `p` שבקוד (נשמר ב-`.pad-key` ליד הגשר); קישור ישן בלי מפתח מציג הודעה לסרוק שוב. טלפון אחד נוהג בכל רגע — טלפון חדש מחליף את הקודם.

## אפשרויות
```
python padbridge.py --port 9663        פורט אחר (9662 עד 9677)
python padbridge.py --no-adb           בלי לחפש טלפון בכבל
python padbridge.py --sim path.html    סימולטור ממקום אחר
python padbridge.py --key 1234         מפתח קבוע
```

## חדש ב-v34
- **מוח הברית לבוטים:** בולם בוחר את היריב שבאמת משחק (לא רובוט שעומד במקום), מאמן לכל ברית מחליט כמה בולמים צריך לפי הניקוד, הזמן והכדורים, מנקדים מתפזרים לעמדות ירי שונות ולא יורים לתוך רובוט, הבולם לומד מאיפה אתה אוהב לירות, וכל הבוטים חונים בסוף האוטונומי ובסוף המאץ׳. בלוח ״יריבים ושותף״ רואים מה כל מאמן החליט ולמה.
- **השופט מדבר עם בני אדם:** מי שנוהג ומצמיד רובוט מקבל התראה כתומה ורטט בשלט אחרי שנייה — לפני שהעבירה נקראת. שחקן ברשת מקבל את ההתראות ואת העבירות שלו אצלו.
- **השהיה:** בחלון החדר רואים כמה מילישניות לוקחת הדרך לכל אורח ובחזרה.
- **סיכום מאץ׳ משותף:** בסוף מאץ׳ עם יותר מנהג אחד — טבלה: מי נהג, ירה, נכנס, דיוק, עבירות, חנה. כל האורחים רואים אותה.

## חדש ב-v35 — האוטונומי נבנה מחדש
- **מבצע אחד לכל מה שנוסע לבד:** המסלול שציירת, מה שהקלטת, האוטונומי של המאץ׳ וכפתור ההדגמה — כולם רצים דרך אותם מנועים ואותה אחיזה, בזמן אמת. נגיעה בסטיק עוצרת.
- **עורך מסלול:** הנקודה הראשונה היא איפה שהרובוט עומד; נקודה בתוך מבנה זזה למקום פנוי; קטע שחוצה מבנה מקבל עקיפה; לכל נקודה פעולה (ירי, איסוף, המתנה, חניה); קו לבן מראה איפה הרובוט באמת נסע.
- **לימוד בהדגמה:** ״הרץ מה שהוקלט״ באמת נוסע, באותו כיוון שנהגת, ו״העבר לעורך״ טוען את ההקלטה לעריכה.
- **במאץ׳:** ״המסלול שלי״ ברשימת האוטונומי. ״אקראי״ כבר לא דורס את מה שבחרת. השגרות הקבועות יוצאות לחניה כשהזמן נגמר.
- **ייצוא RoadRunner:** כיוון נפרד מכיוון הנסיעה (מקנום), פנייה לפתח לפני ירי.
- **תוקן:** הרובוט לא זז בהרצה הראשונה של מסלול (מהירות התאפסה כל פריים).

## חדש ב-v36
- **מסלולים שמורים עם שמות:** ״שמור״, ״טען״, ״מחק״ (בשתי לחיצות). המסלול האחרון עולה לבד בפתיחה הבאה — ככה ״המסלול שלי״ במאץ׳ הוא מה שעבדת עליו.
- **בין מחשבים:** ״העתק כטקסט״ כאן, להדביק בתיבה ו״ייבא מהטקסט״ שם.
- **גרירת נקודות:** במצב סימון גוררים נקודה והעקיפות מסביב נבנות מחדש; נקודה שנגררה לתוך מבנה נצמדת החוצה. לחיצה בלי גרירה עדיין מחליפה פעולה.

## חדש ב-v37
- בדיקה מול G304 במדריך: כל רובוט פותח מאץ׳ עם בדיוק 4 POLLEN (קודם נכנס סוג הכדור שנבחר בלוח).

## חדש ב-v38
- **גרסה קלה** `BIOBUZZ-lab-lite.html`: פי 12 קטנה, אותה פיזיקה ואותה זירה (המודל הרשמי הוא רק תצוגה). אפשר לגרור אליה קובץ CAD אם רוצים.

## חדש ב-v39
- **מיפוי מקלדת** (נהיגה ← ״מקלדת — מה כל מקש עושה״): כמו בשלט — מחליפים את שישת מקשי הנסיעה, ומוסיפים כמה מקשים שרוצים, כל אחד עם פעולה ומצב (לחיצה / מתג / החזקה). חדש בברירת המחדל: שיפט שמאלי = מצב דיוק. נשמר בדפדפן, ושורת הרמזים למטה מתעדכנת.
