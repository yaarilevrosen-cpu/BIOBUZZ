Practice FTC before the robot is ready.

BIOBUZZ is a 3D FTC field simulator: drive with a keyboard or gamepad, test your autonomous, play full matches against bots or friends, and track every driver's stats.

Install in one minute

  1. Download with the button above — it picks the right file for your computer.
  2. Windows: run BIOBUZZ-Setup.exe. If you see “Windows protected your PC” (the app is not code-signed yet), click More info → Run anyway, then Install.
  3. Mac: open the .dmg and drag BIOBUZZ into Applications. The first time, macOS blocks it (not signed by Apple yet): open System Settings → Privacy & Security, scroll down and click Open Anyway. If it says the app is “damaged”, run xattr -dr com.apple.quarantine /Applications/BIOBUZZ.app in Terminal once.
  4. Linux: .deb — sudo apt install ./BIOBUZZ-*.deb. AppImage — chmod +x BIOBUZZ-*.AppImage and run it (on Ubuntu 24.04+ add --no-sandbox if it doesn't start).
  5. Open BIOBUZZ, type your name and (optionally) your team name and number. A one-minute tour shows you around.
  6. Updates — the app checks on every launch. On Windows and Linux (AppImage and .deb) it downloads them for you — .deb asks for your password when you click Install; on Mac it tells you and links to the new download.

Prefer not to install? On Windows the portable version runs straight from the file; on Linux the AppImage does. Your data stays on your computer; signing in to an account (optional) syncs drivers and matches across computers.

What's inside

🎮Drive the fieldKeyboard, gamepad or your phone as a controller. Big magazine display, match clock, referee and scoring.
🤖Autonomous labBuild paths, test start positions and compare against real robot logs.
👥Play togetherSplit screen, local network or phone via QR code. Bots fill the empty spots.
📊Stats for every driverEvery match is saved: averages, records, accuracy and a team table.
📺Broadcast & videoSecond-screen broadcast view and automatic match recording.
🐞Built-in bug reportsFound something odd? One click sends a report with a screenshot.
