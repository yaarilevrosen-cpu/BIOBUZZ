# מוסך 2 וסקאוטינג 2 (גרסה 1.17.0)

## כוונון במוסך
בכל לשונית יש שורת ״⚙ כוונון״. כל שורה מתחילה ב״כמו במעבדה״ — לא משנה כלום.

| שורה | אפשרויות | מה משתנה בפועל |
|---|---|---|
| גלגלי הנעה | 72 / 96 / 104 / 140 מ״מ | קוטר הגלגל: מהירות מול כוח |
| מנוע הנעה | 117 עד 1150 סל״ד | סל״ד ומומנט (מומנט יורד כשהסל״ד עולה) |
| חומר שלדה | אלומיניום, פוליקרבונט, הדפסה, פחמן, פלדה | משקל הרובוט (פלדה ×1.3, פחמן ×0.76) |
| מהירות איסוף | איטי / מהיר | עוצמת המשיכה של האיסוף |
| גלגל תנופה | 72 / 96 / 100 / 120 מ״מ | קוטר גלגל היורה |
| מסת גלגל תנופה | קל / בינוני / כבד | התאוששות בין יריות מול יציבות |
| יחס יורה | 1 / 1.5 / 3 / 4 | יחס המנוע לגלגל |
| זווית יציאה | 45° / 55° / 68° / 75° | זווית הירי |

הבוטים מקבלים את אותו כוונון: גלגל קטן עם מנוע איטי = בוט איטי בהרבה.

## תצוגה חיה
חלון המוסך מראה את הרובוט בתלת־ממד ומתעדכן עם כל שינוי. גוררים כדי לסובב. כפתור ״📐 מלמעלה״ מחזיר לשרטוט.

## סקאוטינג 2 — שדות חדשים בקובץ
- `measured.balls_per_volley` (או `balls_per_cycle` / `shots_per_cycle`) — כמה כדורים במטח
- `measured.volley_sec` (או `shoot_sec`) — בכמה שניות. קובע את הזמן בין יריות של הבוט
- `measured.park_end` — אחוז חניה. בכל מאץ׳ מוגרל אם הבוט חונה
- `measured.reliability` — מתחת ל-99%: תקלה אחת לכל היותר במאץ׳
- `measured.main_shoot_zone` — near / mid / far: טווח הירי המועדף
- `declared.wheel_mm`, `declared.drive_rpm` — לגלגל ולמנוע הקרובים במוסך
- `declared.transfer`, `declared.intake_type`, `declared.color_sensor` — ישר לבנייה

בכל שורה בחלון הסקאוטינג: ״🛠 במוסך״ (עותק לעריכה) ו״🎮 לנהוג בו״. העותק שומר רק את המערכות, בלי מספר הקבוצה.
