## 4. מוסכמות שאסור לשבור
- זירה ±72 אינץ׳. `M()` אינץ׳→מטר, `I()` מטר→אינץ׳. **`z` של הסימולטור = מינוס `y` של ה-CAD.**
- **אדום x שלילי, כחול x חיובי, הקהל ב-z חיובי.** `forward = (sin yaw, 0, cos yaw)`. **Q שמאלה, E ימינה.**
- `BOTS[0]` כחול 1 · `BOTS[1]` כחול 2 · `BOTS[2]` שותף אדום. עמדות `red1 red2 blue1 blue2`.
- כל שחקן אנושי ובוט באותן מגבלות (`AIC`). **המוח לא מוסיף יכולת פיזית — רק החלטות.**
- אזורי טעינה: אדום x≈−62, z∈[−46.6,−23.9]; כחול מראה. מקומות חניה של הבוטים: (±62, ±44) ו-(±62, ±26.5).
