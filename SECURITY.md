# Security Policy

**Please report security vulnerabilities privately:** [open a private security advisory](https://github.com/yaarilevrosen-cpu/BIOBUZZ/security/advisories/new). Do not open a public issue.

The full policy — scope, response targets and safe harbour for good-faith research — is in [legal/security.en.md](legal/security.en.md) (English) and [legal/security.he.md](legal/security.he.md) (Hebrew).

Only the latest release receives security fixes.

מדיניות האבטחה בעברית: [legal/security.he.md](legal/security.he.md).
